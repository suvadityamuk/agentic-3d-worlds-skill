# Blender acceptance criteria

A qualifying example is an actual recorded Blender/bpy modeling task, such as sculpting a ceramic teapot. It includes the bpy creation script, saved scene, self-contained GLB, PNG render, observable trace and native Mesh viewer row. It passes Blender reopen/GLB geometry checks and visual review before contribution.

The previous Three.js examples are retired and are not training examples. Converting those outputs to Blender does not establish bpy creation provenance. Automated test fixtures are synthetic validation data, not contributed user runs.
